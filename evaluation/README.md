# ePdfUB EPUB Evaluation Tool

This tool compares an EPUB generated by `ePdfUB` with a Ground Truth (GT) publisher EPUB to evaluate text extraction accuracy.

## Setup

1. Create a Python virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the script providing the path to your generated EPUB and the GT EPUB:

```bash
python evaluate.py --generated /path/to/generated.epub --gt /path/to/gt.epub --out report.html
```

Open `report.html` in your browser to view the diff.
